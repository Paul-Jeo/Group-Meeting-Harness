# 导师类型画像库

基于虎嗅、澎湃新闻、知乎等平台真实叙事提炼的导师类型学。用于快速识别导师类型并选择对应相处策略。

---

## 三大基础画像

### 类型A：压榨型（Push型）

**核心特征**
- "狠命压榨大老板和苦不堪言小员工的校园版本"
- 要求996出现在工位上，呈现"旺盛的工作状态"
- 组会频率：每周1-2次
- 沟通频率：每天10+条消息
- 学生代价："眼里的光熄灭了，性格变阴沉了，整个人的精神面貌变差了"

**典型话术**
- "这点东西要做这么久？"
- "别人都能做，你为什么不行？"
- "你年轻人应该有冲劲"
- "这是为你好，锻炼能力"

**识别信号**
- 打卡制/签到制
- 朝九晚九+单休
- 月度百分制考核
- 要求学生签字画押

**应对策略**
- **短期**：满足最低服从线，不主动超纲
- **中期**：尽早搞定毕业硬指标，掌握主动权
- **长期**：毕业后迅速切断联系
- **避免**：当面对抗，会被穿小鞋

### 类型B：放养型（Hands-off型）

**核心特征**
- "读到研二下学期，一共见了老师三面"
- "论文装订完了，导师看到封面上的'专业硕士'，才知道我不是学硕"
- 常见于大牛导师/行政职务繁多的导师
- 学生感受："自由气息+找不到人请教的焦虑+毕不了业的担忧"

**典型话术**
- "你自己看着办"
- "我最近比较忙，你先推进"
- "有什么问题再找我"
- "嗯，行"（无进一步反馈）

**识别信号**
- 组会频率低（每月1次或更少）
- 邮件经常不回
- 不记得学生的具体课题
- 学术会议出差频繁

**应对策略**
- **短期**：抓住每次短暂汇报机会，快速获取关键决策
- **中期**：多找师兄师姐/其他老师作为"替代导师"
- **长期**：养成强独立自主能力，把放养当机会
- **避免**：被动等待指导——你会等不到的

### 类型C：理想型（Ideal型）

**核心特征**
- "再生父母型"——操心学业+吃穿用度
- "钱多大方型"——项目有劳务、论文有奖金
- 配备"能力范围内最好的"实验设备和办公用具
- 真心把学生当"学术子女"

**典型话术**
- "这个你不用担心，我来处理"
- "你的发展才是最重要的"
- "想清楚自己要什么，不要被大家裹挟"
- "最近吃饭了吗？气色不太好"

**识别信号**
- 主动关心学生身心状态
- 愿意帮学生协调各方资源
- 毕业后仍保持正面联系
- 组内师门团结

**应对策略**
- 珍惜，真诚投入，用成果回报
- 但保持独立判断，不过度依赖

## 五大衍生画像

### 类型D：情绪不稳型

**核心特征**
- 喜怒无常，表现为"一秒变脸"
- "1分钟前对女儿满脸宠溺，下一秒把学生骂得狗血淋头"
- 可能伴有原生家庭/个人生活的压力转嫁

**识别信号**
- 前一天肯定的事情，第二天全盘否定
- 情绪爆发的触发点不固定
- 其他老师/管理层面前会收敛

**应对策略**
- 避开情绪风暴期（观察规律）
- 重要决策等情绪稳定时再提
- 心理建设：他的情绪和你无关

### 类型E：学术不端型

**核心特征**
- 要求学生挂名不存在的贡献
- 暗示/默许数据修饰
- 抢学生一作、虚报经费
- 让学生代写/代投

**识别信号**
- 让你"修饰"明显不合理的数据
- 论文作者顺序随心所欲
- 拒绝写贡献声明

**应对策略**
- **不参与**——学术不端的成本极高，且不可逆
- 留存所有原始数据和沟通证据
- 必要时向学术委员会申诉
- 最坏情况：换导师

### 类型F：空头支票型

**核心特征**
- 承诺永不兑现（推荐信、项目、一作）
- "画饼大师"——描绘宏大前景
- 学生付出后发现承诺作废

**识别信号**
- 承诺从不变成书面
- 问及兑现时态度转变
- 其他学生的前车之鉴

**应对策略**
- 对所有口头承诺打5折预期
- 关键承诺要邮件确认
- 不为画饼付出超额劳动

### 类型G：师门家长型

**核心特征**
- 要求师门像"家庭"一样
- 频繁聚餐、团建、送礼
- 组内关系密切但边界模糊
- 介入学生私生活

**识别信号**
- 要求加微信好友，关注朋友圈
- 过问恋爱/婚姻
- 组内形成派系

**应对策略**
- 表面融入但保持边界
- 慎防师门内部站队
- 区分"温情"和"操控"

### 类型H：商人导师型

**核心特征**
- 横向项目占主导
- 学生主要做企业项目
- 毕业论文很少管
- 学生可能有项目分红

**识别信号**
- 大量企业合作
- 实验室像公司
- 学生之间分工明确像员工

**应对策略**
- 明确"毕业"和"项目"的时间分配
- 争取将项目成果写入论文
- 养成业界技能为就业做准备

## 识别与匹配指南

### 入组前识别
| 信息源 | 可获取的信息 |
|--------|--------------|
| 师兄师姐（非公开渠道） | 最真实的评价 |
| 导师评价网 | 历史评价数据 |
| 论文署名规律 | 导师是否尊重学生 |
| 毕业生去向 | 导师是否支持就业 |
| 组内学生数量 | 可能的指导密度 |

### 入组后验证
- **前3个月**是验证期——观察导师的真实型
- 注意导师在不同场景下的一致性
- 观察导师对其他学生的态度（不只是对你）
- 询问高年级师兄师姐"导师最近的状态"

### 类型匹配
| 你的类型 | 适合 | 慎选 |
|----------|------|------|
| 自律强+目标明确 | 放养型 | 压榨型（浪费能力） |
| 需要指导+热爱科研 | 理想型 | 放养型（迷失方向） |
| 抗压强+想快速毕业 | 压榨型 | 情绪不稳型 |
| 想就业+学技能 | 商人导师 | 学术型 |
| 心理敏感 | 理想型 | 压榨型/情绪不稳型 |

## 核心洞察

> "导生关系的本质是结构性的不对等，但不对等不意味着必然冲突。
> 冲突源于类型错配：压榨型遇上心理敏感的学生，放养型遇上需要指导的学生。
> 最关键的能力，不是改变导师，而是**准确识别**+**匹配策略**+**必要时止损**。"

**三个不要**
1. 不要试图改变导师的类型
2. 不要把导师当家人（不管他怎么说）
3. 不要在没有毕业硬指标前和导师摊牌

**三个要**
1. 要记录，要保留证据
2. 要发展替代支持系统（师兄师姐/其他老师/外部朋友）
3. 要把"顺利毕业"作为唯一核心指标
