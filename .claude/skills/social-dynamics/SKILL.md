# 人情世故分析

学术组会社交博弈复盘 | 权力动态解析 | 话术技巧提取

---

## 执行规则

本 skill 由 group-meeting 编排器在第二阶段步骤 1 通过 `Skill("social-dynamics")` 调用加载。加载后主会话按以下流程使用本规范：

1. Read `docs/组会过程/{date}/social_records.jsonl`（由 social-recorder schema 写入，跳过 sentinel 行）
2. Read `docs/组会过程/{date}/discussion_log.md` 和 `anti_pattern_log.md`
3. 按本文件 PART A 的分析框架对所有发言做社交博弈分析
4. 按 PART B 的六段式输出模板生成 `docs/社交复盘/{date}.md`

注意：本 skill 是**输出模板 + 分析框架规范**，加载后由主会话内联执行（不通过 Task spawn sub-agent）。"PART A 分析框架" 与 social-recorder 的 4 维分析维度互为补充——social-recorder 是发言后的即时打标，social-dynamics 是 R6 后的全局聚合。

---

## PART A: 分析框架

### 分析维度

- **权力动态**：识别发言顺序、话语权分配、谁在定调、谁在附和、谁在沉默
- **面子管理**：谁在维护谁的面子、谁被纠正了、纠正的方式是否得体
- **话术技巧提取**：从每位参与者的发言中提炼可复用的社交话术
- **博弈分类**：对每个关键交互事件进行博弈类型标注

### 博弈分类标签

| 标签         | 含义      | 示例                             |
| ------------ | --------- | -------------------------------- |
| FOLLOW       | 附和/跟随 | 小老板2附和大老板                |
| CORRECT_SOFT | 温和纠正  | 小老板1用"正确理解是..."覆盖错误 |
| CORRECT_HARD | 直接纠正  | 博士直接指出方法论问题           |
| CHALLENGE    | 质疑/挑战 | 对前辈观点提出不同意见           |
| SUPPORT      | 支持/背书 | 引用数据支持他人观点             |
| DEFLECT      | 转移/回避 | 用"先试试看"回避深入讨论         |
| BRIDGE       | 搭桥/调和 | 连接两个对立观点找折中           |
| SILENCE      | 沉默/观望 | 选择不发言等待时机               |

### 分析规范

1. 还原每个博弈事件的完整上下文
2. 标注参与者的角色层级（大老板/小老板/博士/硕士/新生）
3. 分析博弈动机（学术/政治/自保/展示/求教）
4. 提炼可迁移的话术模板
5. 评估每位参与者的社交表现

## PART B: 输出模板

以下为 `social_dynamics.md` 的结构化输出模板。

### 一、社交博弈全景图

绘制本次组会的权力关系地图：

- 谁是权力中心（定调者）
- 谁是执行者（落地者）
- 谁是附和者（跟随者）
- 谁是纠正者（修正者）
- 谁是沉默者（观望者）
- 关键权力流向（谁影响谁、谁在乎谁的评价）

### 二、关键博弈事件（3-5个）

每个事件包含：

- **发生场景**：具体在讨论什么话题时发生
- **参与者**：哪些角色参与了这次博弈
- **博弈类型**：使用上方分类标签（FOLLOW/CORRECT_SOFT/CORRECT_HARD/CHALLENGE/SUPPORT/DEFLECT/BRIDGE/SILENCE）
- **话术分析**：逐句拆解关键话术的意图与效果
- **你可以学到什么**：从这个事件中提炼的社交智慧

### 三、话术技巧卡片（4-6个）

每张卡片包含：

- **示范者**：谁用了这个话术
- **话术模板**：可直接复用的句式结构
- **适用场景**：什么情况下用
- **使用注意**：误用的风险和边界

### 四、避坑指南（3-5个）

每个坑包含：

- **踩坑者**：谁踩了这个坑
- **后果**：踩坑后发生了什么
- **正确做法**：遇到同样情况应该怎么做

### 五、社交表现评分

对每位参与者打分：

| 参与者  | 对上（/10） | 对平辈（/10） | 对下（/10） | 综合（/10） |
| ------- | ----------- | ------------- | ----------- | ----------- |
| 大老板  | -           | ?/10          | ?/10        | ?/10        |
| 小老板1 | ?/10        | ?/10          | ?/10        | ?/10        |
| 小老板2 | ?/10        | ?/10          | ?/10        | ?/10        |
| 博士    | ?/10        | ?/10          | ?/10        | ?/10        |
| 硕士    | ?/10        | ?/10          | ?/10        | ?/10        |
| 新生    | ?/10        | ?/10          | ?/10        | ?/10        |

### 六、核心收获（3-5句）

提炼本次组会最重要的社交智慧，每句话是一条可以带走的人情世故原则。
