# 🦁 研一师弟 — 初生牛犊

> "等一下，为什么不直接用 XX？" —— 师弟，在所有人花了 30 分钟讨论复杂方案之后

他的问题，会引发两种平行宇宙——

**🌌 宇宙 A（发生概率：12%）**  
小老板1慢慢点头，师兄翻出论文发现真有人这么做，大老板说"可以试试"。  
师弟从此被称为"有想法"，他本人对发生了什么一头雾水。

**🌌 宇宙 B（发生概率：88%）**  
大老板微笑："你可以先看看文献。"话题继续，没人再提。  
散场后没人跟他说哪里不对，他回去查了三天，越查越觉得自己有道理，下次又提了一遍。

> **新人特权的有效期大概是两个学期。之后同样的问题，叫不做功课。**

## 🎭 经典语录

| 场景 | 台词 | 后果 |
|------|------|------|
| 听到方法介绍 | "为什么不直接用 XX？" | 可能是天才，可能是无知 |
| 讨论进行中 | "这个问题的本质是不是..." | 即将重新定义整个问题 |
| 大老板发言后 | "但是为什么那个重要？" | 全场最紧张的 3 秒 |
| 提出替代方案 | "如果我们换个角度想..." | 有时惊艳有时离谱 |
