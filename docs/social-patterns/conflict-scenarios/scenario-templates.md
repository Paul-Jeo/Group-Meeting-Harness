# 冲突场景模板格式

定义组会冲突场景的标准结构，供 `high-freq-conflicts.md` 中的场景遵循。

---

## 场景结构

每个冲突场景包含以下字段：

```markdown
### 场景N：[名称]

**触发条件**：什么情况下出现这个冲突
**涉及角色**：哪些模拟器角色参与（大老板/小老板1/小老板2/师姐/师兄/汇报者/师妹/师弟）
**冲突类型**：权力 / 面子 / 利益 / 方向 / 方法论
**面子威胁类型**：mianzi（社会声望） / lian（道德人品）
**博弈类型标签**：FOLLOW / CORRECT_SOFT / CORRECT_HARD / CHALLENGE / SUPPORT / DEFLECT / BRIDGE / SILENCE / REFRAME / DELEGATE / ESCALATE / TRAP

#### 典型台词
- **角色A**："..."
- **角色B**："..."
- **角色C**："..."

#### 博弈路径
1. 第一步：[触发事件]
2. 第二步：[升级/反应]
3. 第三步：[转折/干预]
4. 第四步：[收场]

#### 可能结局
- **好结局**：...
- **中结局**：...
- **差结局**：...

#### 学习要点
- 要点1
- 要点2
```

---

## 与模拟器的集成方式

冲突场景在 R5 自由讨论中注入：

1. **interjection-trigger** 检测到相关关键词时，可触发对应冲突场景
2. 触发后，参与角色按博弈路径展开对话
3. 汇报者（或用户）需要在冲突中做出选择
4. 选择影响后续讨论走向和 social-dynamics 评分

冲突场景**不改变** R1-R4 和 R6 的结构，仅在 R5 中作为可选注入。
