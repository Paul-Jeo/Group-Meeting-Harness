# 10个高频冲突场景

基于知乎/小木虫/科学网真实案例提炼，每个场景含完整对话和博弈路径。

---

### 场景1：当众被否定整个方向

**触发条件**：汇报者展示研究方向后，大老板认为方向错误
**涉及角色**：大老板、汇报者、师姐（解围）
**冲突类型**：方向 + 面子
**面子威胁**：mianzi（当众否定能力判断）
**博弈标签**：REFRAME / DEFLECT

#### 典型台词
- **大老板**："这个方向...我觉得可能需要重新想一想。现在学界已经不太做这个了。"
- **汇报者**："（内心崩溃）谢谢老师指出来，我回去重新调研一下..."
- **师姐**："其实学弟/学妹之前的积累不全是白费，里面XX部分的数据处理思路挺好的，说不定可以迁移到新方向上。"

#### 博弈路径
1. 大老板用间接方式否定（"可能需要重新想"而非"这个不行"）
2. 汇报者面子受损，全组注视
3. 师姐介入解围，保留汇报者部分工作价值
4. 大老板收尾："嗯，你先调研一下，下次组会再讨论"

#### 可能结局
- **好**：会后私下找大老板深聊，获取真实方向指引
- **中**：按新方向调研，旧工作部分保留
- **差**：当场激烈反驳，大老板不高兴，后续被冷处理

#### 学习要点
- 当众被否时不要辩解，先接受再私下沟通
- 师姐的"部分价值保留"话术值得学习

### 场景2：大小老板意见相反

**触发条件**：大老板和小老板对同一课题给出矛盾指令
**涉及角色**：大老板、小老板1、汇报者
**冲突类型**：权力
**面子威胁**：mianzi（选边站=得罪另一方）
**博弈标签**：BRIDGE / DEFLECT

#### 典型台词
- **大老板**："这个课题要从理论角度深入，做出framework来。"
- **小老板1**：（私下）"大老板说的太理想化了，咱们先把实验结果跑出来再说理论。"
- **汇报者**：（内心：我到底听谁的？）"好的老师，我两边都推进一下。"

#### 博弈路径
1. 大老板定调理论方向
2. 小老板私下给出相反的实务建议
3. 汇报者两面应承
4. 实际按小老板建议执行，组会上用大老板的理论框架包装

#### 可能结局
- **好**：两边都不得罪，实际走务实路线，汇报用理论包装
- **中**：被一方发现你偏向另一方，但及时解释
- **差**：两边都做不好，双方都不满意

#### 学习要点
- 核心原则："内外有别"——日常听小老板，组会表演给大老板
- 绝不在一方面前评价另一方

### 场景3：师兄的方法被你的实验推翻

**触发条件**：你的实验数据表明师兄之前用的方法有问题
**涉及角色**：师兄、汇报者、师姐（调和）
**冲突类型**：面子 + 方法论
**面子威胁**：mianzi（否定师兄的技术判断）
**博弈标签**：CORRECT_SOFT / BRIDGE

#### 典型台词
- **汇报者**："我用XX方法跑了一下，发现和师兄之前的结果有一些出入..."
- **师兄**："你参数设对了吗？我当时跑出来是没问题的。"
- **师姐**："可能是数据集版本不一样？两个结果都有参考价值，说不定反映的是不同条件。"

#### 博弈路径
1. 汇报者用"有一些出入"而非"师兄错了"引入
2. 师兄本能防御，质疑你的实验设置
3. 师姐打圆场，给双方都留面子
4. 后续私下和师兄核实参数差异

#### 学习要点
- 永远不要说"师兄的方法错了"，说"结果有出入"
- 让数据说话，不做人身判断

### 场景4：被问到完全不会的问题

**触发条件**：导师或同门问了一个你完全没考虑过的问题
**涉及角色**：大老板/师兄、汇报者
**冲突类型**：面子
**面子威胁**：mianzi（当众暴露知识盲区）
**博弈标签**：DEFLECT

#### 典型台词
- **大老板**："你考虑过XX因素对结果的影响吗？"
- **汇报者**："（2秒停顿）这个角度我确实还没有深入研究，但基于目前的数据，我初步判断影响可能不大。我回去做一个专门的分析，下次汇报。"

#### 博弈路径
1. 被问到盲区，全场沉默1-2秒
2. 停顿（不慌），组织语言
3. 诚实承认 + 给出初步判断 + 承诺跟进
4. 迅速转到下一个话题

#### 学习要点
- 2秒停顿显示思考而非恐慌
- "还没深入研究"比"不知道"好10倍
- 承诺跟进=展示负责态度

### 场景5：有人声称"这个我之前想过"

**触发条件**：你汇报一个新想法，有人马上说"我也想过"
**涉及角色**：师兄/同门、汇报者
**冲突类型**：利益（idea归属）
**面子威胁**：mianzi（创新性被质疑）
**博弈标签**：CHALLENGE / SUPPORT

#### 典型台词
- **同门**："哎这个我之前也想过，不过一直没来得及做。"
- **汇报者**："是吗？那太好了！你之前有做过相关的预实验或者调研吗？如果有的话可以整合进来，我们一起推进。"

#### 博弈路径
1. 同门声称自己也有类似想法
2. 汇报者反将一军：要求对方提供证据
3. 如果对方没有任何记录→idea归属不变
4. 如果对方确实有草稿→协商合作或区分角度

#### 学习要点
- "想过"不等于"做过"，要求看证据
- 反将一军时保持友好语气："太好了我们可以合作"

### 场景6：组会上被要求临时改实验

**触发条件**：导师在听完汇报后即兴提出新实验要求
**涉及角色**：大老板、汇报者、小老板1（协调）
**冲突类型**：权力 + 方向
**面子威胁**：mianzi（拒绝=不听话）
**博弈标签**：FOLLOW / BRIDGE

#### 典型台词
- **大老板**："你回去把XX也跑一下，应该很快的。"
- **汇报者**："好的老师，我评估一下工作量，争取这周出结果。"
- **小老板1**："老师的意思落地的话，可以先做一个简化版本的XX，验证可行性再全面展开。"

#### 博弈路径
1. 大老板即兴发散，提出新实验
2. 汇报者先接受（不当场拒绝）
3. 小老板1翻译为可执行的简化版本
4. 实际执行简化版，下次组会汇报

#### 学习要点
- 大老板说"很快"=他不关心你要多久
- 先接受，和小老板1协商实际执行方案

### 场景7：小老板给的建议全是错的

**触发条件**：小老板2热情地给了一堆建议，你直觉感觉不对
**涉及角色**：小老板2、汇报者、师兄（纠正）
**冲突类型**：方法论 + 面子
**面子威胁**：mianzi（质疑上级=得罪人）
**博弈标签**：TRAP / CORRECT_HARD

#### 典型台词
- **小老板2**："这个方向太好了！你直接把两个模型融合一下，效果肯定翻倍！"
- **汇报者**："（内心：这好像不对...）嗯...我回去试试看。"
- **师兄**："融合之前可能要先看看两个模型的假设是否兼容，不然融合可能反而更差。"

#### 博弈路径
1. 小老板2热情给出错误建议
2. 汇报者犹豫但不敢当面反驳
3. 师兄用事实纠正，不给小老板2面子
4. 汇报者私下按师兄建议执行

#### 学习要点
- 热情程度和正确程度不成正比
- 不确定时说"我回去试试看"是安全的缓冲
- 私下找师兄/师姐核实

### 场景8：同门对比施压

**触发条件**：导师用其他同学的进度来施压你
**涉及角色**：大老板、汇报者
**冲突类型**：面子 + 权力
**面子威胁**：mianzi（当众被比下去）
**博弈标签**：SILENCE / DEFLECT

#### 典型台词
- **大老板**："你看看师兄，同样的时间，人家已经发了两篇了。"
- **汇报者**："确实需要加快节奏，我这周把XX先推进一步，争取尽快出初稿。"

#### 博弈路径
1. 导师当众对比（可能是全员施压策略）
2. 汇报者不接对比的话茬
3. 只谈自己的具体计划和时间节点
4. 不说"别人课题简单"——这是最大禁忌

#### 学习要点
- 不在对比框架里应答
- 转向行动计划，用具体性化解泛化批评
- 组内交流后可能发现每个人都被对比过

### 场景9：没有进展的组会汇报

**触发条件**：这周确实没做什么，但必须汇报
**涉及角色**：大老板、汇报者
**冲突类型**：面子
**面子威胁**：mianzi（被认为在摸鱼）
**博弈标签**：REFRAME / DEFLECT

#### 典型台词
- **大老板**："小X，这周做了什么？"
- **汇报者（三段式）**："这周主要在调试XX环节，遇到了一个数据预处理的问题，尝试了A和B两种方案但效果都不理想。我查了相关文献发现C方案可能可行，想请教老师觉得这个思路是否合理？"

#### 博弈路径
1. 导师点名汇报
2. 用三段式（做了什么→遇到什么困难→下一步计划）
3. 把焦虑转移给导师："想请教老师觉得..."
4. 导师进入讨论模式，忘记追问产出

#### 学习要点
- 汇报"问题"而不是汇报"进展"
- 三段式结构让空白内容也有结构感
- 反客为主：提问把导师从考核者变为讨论者

### 场景10：导师画大饼后的落地讨论

**触发条件**：大老板提了一个宏大到不可能实现的想法
**涉及角色**：大老板、小老板1、汇报者
**冲突类型**：方向（理想vs现实）
**面子威胁**：无直接威胁（但需要技巧性缩小范围）
**博弈标签**：BRIDGE

#### 典型台词
- **大老板**："如果能把这个做成一个通用框架，和医疗AI结合起来，那就是Nature的工作。"
- **小老板1**："老师的方向落地的话，我觉得可以分三步走：第一步先在我们的数据集上验证核心模块，第二步扩展到相关领域，第三步再考虑通用化。"
- **汇报者**："我先把第一步做扎实，争取下次组会给大家看初步结果。"

#### 博弈路径
1. 大老板造火箭级idea
2. 小老板1翻译为三步走计划（缩小10倍）
3. 汇报者只承诺第一步（再缩小3倍）
4. 大老板满意地点头："嗯，你先试试看"

#### 学习要点
- 大饼的价值在于方向信号，不在于字面执行
- 小老板1的"分步走"是把火箭变自行车的标准话术
- 只承诺最近一步，保留调整空间
