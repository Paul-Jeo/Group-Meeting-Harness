# 扩展冲突场景（复杂博弈 + 高压场景）

补充 high-freq-conflicts.md 的10个基础场景，覆盖团队分化、导师操控、毕业阶段、线上组会等复杂维度。

---

### 场景11：导师红脸白脸——大小老板唱双簧

**触发条件**：大老板和小老板配合施压，一个骂一个安慰
**涉及角色**：大老板、小老板1、汇报者
**冲突类型**：权力操控
**面子威胁**：mianzi（被系统性施压）
**博弈标签**：DELEGATE / TRAP

#### 典型台词
- **大老板**：（严厉）"你这个进度太慢了，再这样下去你毕不了业。"
- **小老板1**：（私下找你）"老师今天只是着急，他其实很看好你。你先把XX做出来，我帮你和老师说。"
- **汇报者内心**：感动于小老板的"帮忙"，加倍努力——但这正是他们要的效果

#### 博弈路径
1. 大老板组会上严厉批评（制造恐惧）
2. 小老板私下安慰+给出"解决方案"（制造感恩）
3. 学生被引导到两人都想要的方向上
4. 循环往复——恐惧和感恩交替，学生完全被控制节奏

#### 可能结局
- **好**：识破套路后保持理性，只关注自己的毕业核心指标
- **中**：被节奏带着走但勉强完成任务
- **差**：被情绪操控，过度依赖小老板，失去独立判断

#### 学习要点
- 红脸白脸是最经典的管理术——识别"被安慰"是否在引导你做特定事
- 不要因为被骂就慌，也不要因为被安慰就感恩到失去判断
- 始终锚定自己的核心目标：毕业条件是什么，我做了多少

### 场景12：同门分化——实验室派系站队

**触发条件**：课题组形成两个小团体，新人被迫选边站
**涉及角色**：汇报者、师兄A（派系1）、师姐B（派系2）
**冲突类型**：利益 + 面子
**面子威胁**：mianzi（被排挤/被贴标签）
**博弈标签**：SILENCE / BRIDGE

#### 典型台词
- **师兄A**：（私下）"跟你说实话，师姐B那个方向不太行，导师也不看好。你跟着我做更有前途。"
- **师姐B**：（私下）"师兄A那人表面对你好，其实是想拉你当劳动力。小心点。"
- **汇报者内心**：两边都在拉拢我，说对方坏话，我到底信谁？

#### 博弈路径
1. 新人入组，两个"老人"分别拉拢
2. 各自透露对方的"黑料"
3. 新人如果站队→另一方冷处理
4. 新人如果中立→可能两边都不帮你

#### 可能结局
- **好**：保持中立，和每个人都维持基本友好，专注自己课题
- **中**：靠近一方但保持和另一方的表面关系
- **差**：明确站队后被另一方在导师面前说坏话

#### 学习要点
- 绝不在一方面前说另一方的坏话——实验室是熟人社会，任何话都会传
- 不主动参与派系，用"我刚来还在学习"做挡箭牌
- 观察导师更倾向哪一方，但不要表态

### 场景13：导师偏心——差异化对待

**触发条件**：导师明显给某个学生更多资源/关注，其他学生感到不公
**涉及角色**：大老板、被偏爱的同门、汇报者
**冲突类型**：利益 + 面子
**面子威胁**：mianzi（被忽视=能力不被认可）
**博弈标签**：SILENCE / REFRAME

#### 典型台词
- **大老板**：（对被偏爱的同门）"你这个做得很好，继续深入。经费这边我给你安排。"
- **大老板**：（对你）"嗯...你那个继续做吧。"（敷衍一句带过）
- **汇报者内心**：同样的工作量，为什么TA得到的资源和关注是我的三倍？

#### 博弈路径
1. 观察到导师对不同学生的差异化投入
2. 内心不平但不敢直接提出
3. 选择是：加倍努力争取关注 / 私下找导师谈 / 找小老板帮忙传达
4. 关键：不能表现出嫉妒，要用"请教"方式争取资源

#### 可能结局
- **好**：主动找导师展示进展+"请教"后续方向，用成果争取关注
- **中**：默默接受，把有限资源最大化
- **差**：当面抱怨不公平，被导师反感

#### 学习要点
- 导师偏心有时是"投资回报率"判断——你需要证明投资你有回报
- 永远不要在同门面前表达嫉妒
- 用成果说话，主动汇报是最好的"争宠"方式

### 场景14：论文被拒后的组会汇报

**触发条件**：投稿被reject，需要在组会上汇报这个结果
**涉及角色**：大老板、汇报者、师姐（安慰）
**冲突类型**：面子
**面子威胁**：mianzi（当众承认失败）
**博弈标签**：REFRAME / SUPPORT

#### 典型台词
- **汇报者**："这篇投到XX会议，收到了reject。reviewer主要的意见是ABC三点，我分析了一下觉得A和B是合理的，C可能是误解。"
- **大老板**："嗯，reviewer说的A点确实是个问题。你回去先把这个解决了，改完投下一个。"
- **师姐**："被拒很正常的，我第一篇也被拒了三次才中。reviewer说的A那个其实不难改。"

#### 博弈路径
1. 汇报者需要当众承认被拒（面子损失）
2. 关键话术：不说"被拒了"，说"收到了reviewer的反馈"
3. 主动分析reviewer意见（展示理性而非沮丧）
4. 大老板和师姐分别给建设性反馈

#### 学习要点
- 被拒是常态，如何汇报被拒比被拒本身更重要
- "收到reviewer反馈"比"被reject"好100倍
- 主动分析意见+提出改进方案=展示学术成熟度

### 场景15：导师喜怒无常——情绪过山车

**触发条件**：导师上一秒还在夸你，下一秒突然翻脸
**涉及角色**：大老板、汇报者
**冲突类型**：权力 + 面子
**面子威胁**：mianzi + lian（措手不及的公开否定）
**博弈标签**：SILENCE / DEFLECT

#### 典型台词
- **大老板**：（翻到PPT第3页）"嗯不错不错，这个数据挺好的。"
- **大老板**：（翻到第5页）"等等，这是什么？你这个实验设计有问题吧？上周不是让你改了吗！"
- **汇报者**："（懵了）呃...老师，这个我确实改了，但..."
- **大老板**："改了？改成这样？"

#### 博弈路径
1. 前半段正常甚至被夸
2. 某个触发点导致导师突然翻脸
3. 全场气氛骤降
4. 关键：不要辩解，不要慌，等导师说完再回应

#### 可能结局
- **好**：沉稳应对——"好的老师，这个点我回去重新处理"（不纠缠）
- **中**：当场尝试解释但被打断
- **差**：慌张辩解，导师更生气

#### 学习要点
- 导师翻脸可能和你无关——可能是他自己的压力转移
- 提前做"想象脱敏"——预想最坏情况，降低真实发生时的冲击
- 被骂时的2秒沉默比任何回应都有效

### 场景16：开题被否——方向全面推翻

**触发条件**：开题答辩时，评委（或导师）否定了你的整个选题
**涉及角色**：大老板、答辩评委、汇报者
**冲突类型**：方向 + 面子（最严重级别）
**面子威胁**：mianzi + lian（公开的专业能力否定）
**博弈标签**：DEFLECT / BRIDGE

#### 典型台词
- **评委**："这个选题的创新点在哪里？我看不出来和已有工作有什么本质区别。"
- **导师**：（不帮你说话，沉默看你）
- **汇报者**："感谢老师的意见。目前的差异化主要体现在XX方面，但确实还需要进一步明确。我回去会在这个方向上做更深入的论证。"

#### 博弈路径
1. 评委提出根本性质疑
2. 导师可能帮你解围，也可能保持沉默（看你怎么应对）
3. 如果导师沉默=他也觉得有问题
4. 诚恳接受+承诺改进是唯一安全出路

#### 学习要点
- 开题被否不是终点——大多数人的开题都改过至少一次
- 导师在答辩场上沉默通常意味着他也认为需要调整
- 记录所有评委意见，会后逐条回应

### 场景17：线上组会——摄像头博弈

**触发条件**：线上组会，开不开摄像头成为权力展示
**涉及角色**：大老板、全体成员
**冲突类型**：权力（监控 vs 自由）
**面子威胁**：低（但心理压力大）
**博弈标签**：FOLLOW / DEFLECT

#### 典型台词
- **大老板**："把摄像头都打开。"
- **学生A**：（打开，但用虚拟背景遮住乱七八糟的宿舍）
- **学生B**：（"老师不好意思我摄像头坏了"）
- **学生C**：（打开OBS虚拟摄像头循环播放预录视频）

#### 博弈路径
1. 导师要求开摄像头=要求"在场证明"
2. 学生有多种规避策略
3. 导师可能随机点名提问来验证是否"真人在线"
4. 被发现作假=信任崩塌（lian层面）

#### 学习要点
- 线上组会的核心博弈是"注意力控制权"
- "网络卡了"是万能借口但不能多用
- 最安全策略：真人在线，少说话但随时能被点名

### 场景18：被迫做与毕业无关的横向项目

**触发条件**：导师安排你做企业横向项目，和你的论文方向完全不相关
**涉及角色**：大老板、汇报者
**冲突类型**：利益（导师利益 vs 学生毕业）
**面子威胁**：低（但影响毕业进度）
**博弈标签**：BRIDGE / DEFLECT

#### 典型台词
- **大老板**："XX企业那边的项目你来负责一下，下个月要交报告。"
- **汇报者**："好的老师。不过我目前毕业论文还差XX部分，能不能先集中把论文推进一下？"
- **大老板**："论文的事不急，先把项目做了。"

#### 博弈路径
1. 导师以项目经费为由安排横向任务
2. 学生不敢拒绝但担心影响毕业
3. 尝试谈判："能不能两边都推进？"
4. 现实：横向项目挤占了全部时间

#### 可能结局
- **好**：在横向项目中找到和论文的交叉点，一石二鸟
- **中**：硬扛两条线，质量都打折
- **差**：论文严重滞后，被迫延毕

#### 学习要点
- 接受横向项目时立刻和导师确认"对毕业进度的影响"
- 尝试将横向内容融入论文——这是最优解
- "先做完项目再写论文"是陷阱——项目永远做不完

### 场景19：同门抢功——"这个我之前做过"

**触发条件**：你在组会上汇报一个成果，同门声称自己也做过/贡献了
**涉及角色**：汇报者、同门师兄、导师
**冲突类型**：利益（署名/成果归属）
**面子威胁**：mianzi（创新性被稀释）
**博弈标签**：CHALLENGE / DELEGATE

#### 典型台词
- **汇报者**："这个新方法在我们的数据上提升了8个点..."
- **师兄**："哦这个啊，之前我也试过类似的想法，代码框架都是我搭的。"
- **导师**：（看向你）"是这样吗？"
- **汇报者**："师兄之前确实做了基础框架，在这个基础上我做了XX改进，这8个点的提升来自YY改动。"

#### 博弈路径
1. 同门当众声称自己有贡献
2. 导师要求确认
3. 关键：清晰区分各自贡献，不否认对方但突出自己增量
4. 后续：和导师私下沟通署名安排

#### 学习要点
- 实验过程全程保留记录（git commit log、实验日志）
- 汇报时主动说明"在XX基础上我做了YY"——先承认再突出
- 私下和导师确认署名比在组会上争论安全100倍

### 场景20：毕业答辩——评委连环追问

**触发条件**：毕业答辩时评委针对薄弱点连续追问
**涉及角色**：答辩评委、汇报者、导师（可能兜底）
**冲突类型**：面子 + 方法论
**面子威胁**：mianzi（当众被质疑研究水平）
**博弈标签**：DEFLECT / REFRAME

#### 典型台词
- **评委**："你这个方法和XX方法有什么本质区别？"
- **汇报者**："主要区别在于..."
- **评委**："但是XX方法已经能达到类似效果了，你的contribution在哪里？"
- **汇报者**："除了性能上的差异，我们的方法在YY维度上有独特优势..."
- **导师**：（如果看你实在扛不住）"我补充一下，这个工作的核心贡献其实是..."

#### 博弈路径
1. 评委连续追问某个薄弱点
2. 每次回答后被进一步追问
3. 关键：保持冷静，每次回答控制在30-60秒
4. 如果真的答不上来→"这是一个很好的方向，我会在后续工作中深入研究"
5. 导师可能在关键时刻介入兜底

#### 学习要点
- 答辩准备时预演"最难的10个问题"
- 2秒停顿规则——显示思考而非恐慌
- 导师兜底台词的经典形式："徒儿退下，为师替你舌战群儒"
