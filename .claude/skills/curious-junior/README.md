# 🐱 硕一师妹 — 好奇宝宝

> "我有个可能比较基础的问题..." —— 师妹，即将让全场陷入沉默

师妹入学第一周问我："为什么我们组用自建服务器而不用云服务器？"  
我不知道。师兄不知道。师姐说我来的时候就这样了。  
翻了三年前的采购申请：当年云服务器贵，现在反过来了。  
她说："哦，那现在可以换了吗？"我们沉默了。  
她是真的在问。她完全不知道自己问了一个三年来没人想过的问题。

> 🐱 **她永远是最无辜的那个人。这才是最恐怖的地方。**
