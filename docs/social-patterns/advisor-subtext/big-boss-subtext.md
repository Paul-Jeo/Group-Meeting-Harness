# 大老板弦外之音库

组会场景中大老板（院士/PI级）的话术潜台词解码。

## 使用方式

- **角色 agent**：big-boss-agent 发言时可从本库选取话术变体，增加表达多样性
- **social-dynamics**：分析时可引用本库中的模式编号标注潜台词
- **汇报者**：学会"听话听音"，识别弦外之音

## 弦外之音速查表

按严重程度排序，用于快速识别：

### CRITICAL（需立即重视）
- "送去盲审就是自杀" → 论文远未达标
- "我在教育界名誉扫地" → 写作质量极差
- "我又重新思考了下" → 可能要换课题
- "I only have a few minor comments" → 请重写
- "With the greatest respect..." → 你完全错了

### HIGH（需要认真对待）
- "格局再大一点" → 太小了重做
- "你可以先试试看" → 不看好
- "你们几个我最担心你" → 全员施压
- "很简单的你应该很快做出来" → 压力测试
- "这个做法比较常规" → 没创新
- "Have you considered X?" → 必须做X

### MEDIUM（正常施压）
- "最近在忙什么？" → 怀疑摸鱼
- "不好好干��怎么毕业" → 常规鞭策
- "总体不错但要调整" → 薛定谔评价
- "嗯，行" → 不确定是否满意

### LOW（不必紧张）
- "如果能和XX结合就是Nature" → 画大饼，提取可行部分
- "这个领域的未来在于..." → 宏观叙事
- "耽误大家两分钟" → 准备坐30分钟
