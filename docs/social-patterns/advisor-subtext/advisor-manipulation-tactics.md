# 导师操控术识别库

识别导师常用的结构化操控手段，供学生防御 + social-dynamics 分析引用。

> **使用原则**：本库不为复制操控行为而存在，而是为被操控的学生提供识别框架和应对策略。

---

## 一、情感操纵类（Emotional Manipulation）

### M01 杀鸡儆猴
- **手段**：选一个相对弱势的学生重点批评，在全组面前树立威权
- **识别线索**：同样的错误，只对某一个人重点发作
- **潜台词**："我让你看看反抗的下场"
- **应对**：被选中时保持冷静，不反驳；没被选中时不要庆幸，下一次可能是你

### M02 喜怒无常
- **手段**：情绪毫无征兆地切换，上一秒夸你下一秒骂你
- **识别线索**：批评的触发点和内容无关，和他自己的情绪状态相关
- **潜台词**："我的情绪你必须时刻揣摩"
- **应对**：把导师情绪当"天气"，不内化为"自己做错了"

### M03 群体施压——"每个人都被说过最担心你"
- **手段**：对每个学生说"你是我最担心的那个"，制造个人焦虑
- **识别线索**：组内交流发现每个人都被说过同样的话
- **潜台词**："我要你时刻处于危机感中"
- **应对**：组内私下交流，集体免疫

### M04 冷处理/冷暴力
- **手段**：对学生不回消息、不看论文、不签字，消耗到学生主动让步
- **识别线索**：对其他学生正常回应，只对你冷处理
- **潜台词**："我在表达不满，但我不想留下证据"
- **应对**：用邮件而非微信沟通，建立正式通讯记录

### M05 画大饼+不兑现
- **手段**：承诺各种前景（推荐信、一作、项目）但永不兑现
- **识别线索**：承诺从不变成白纸黑字
- **潜台词**："我用未来的可能性换你当下的付出"
- **应对**：关键承诺尽量走书面/邮件，对口头承诺打折预期

## 二、信息不对称类（Information Asymmetry）

### M06 模糊标准
- **手段**：不明确说毕业要求是什么，随时可以说"你还不够"
- **识别线索**："再努力一下""这还不够好"等模糊评价
- **潜台词**："决定权永远在我手里"
- **应对**：主动确认"毕业条件是什么"，并留下书面记录

### M07 翻旧账
- **手段**：用过去的错误反复攻击学生
- **识别线索**："你上次不是也这样""你总是这样"
- **潜台词**："你永远有原罪"
- **应对**：只讨论当前问题，不接翻旧账的话茬

### M08 选择性记忆
- **手段**：自己说过的话装作没说过，反而责怪学生
- **识别线索**："我什么时候说过这个？"—— 但你有记忆
- **潜台词**："我的版本就是真相"
- **应对**：关键指示当场复述一遍+邮件确认

### M09 "我这都是为你好"
- **手段**：用"为你好"包装不合理要求
- **识别线索**：要求实际只对导师有利，对你无利
- **潜台词**："你反对我=你不识好歹"
- **应对**：区分"真的为你好"（有长期收益）vs"借为你好"（只有导师收益）

## 三、劳动剥削类（Labor Exploitation）

### M10 "锻炼机会"包装
- **手段**：把和毕业无关的杂活包装成"机会"让你做
- **识别线索**：做完后不能写进简历/论文的任务
- **潜台词**："你做了也白做，但做了才算听话"
- **应对**：评估每个任务"能否写进毕业论文或简历"

### M11 压力测试——半夜找活
- **手段**：深夜布置任务，测试你的服从底线
- **识别线索**：深夜消息+要求次日早晨完成
- **潜台词**："我想知道能榨到哪一步"
- **应对**：第二天早晨回复（不即时），说"昨晚没看到消息，今天立即处理"

### M12 周末全占
- **手段**：周末临时布置任务让你无法休息
- **识别线索**：周五下午布置周一要的东西
- **潜台词**："你的时间就是我的时间"
- **应对**：提前安排"周末已有安排"的默认回应

### M13 横向项目绑架
- **手段**：让学生做企业横向项目，挤占论文时间
- **识别线索**：项目和毕业论文毫无关系
- **潜台词**："你的毕业要先服务于我的经费"
- **应对**：接受时立刻确认对毕业进度的影响，尝试让项目和论文有交叉

## 四、署名操纵类（Authorship Manipulation）

### M14 偷换一作
- **手段**：论文投稿前把一作从学生改为导师
- **识别线索**：投稿前才突然讨论署名
- **潜台词**："你做了就是我的"
- **应对**：撰写初期就用邮件确认署名分工

### M15 "我署名只是为了好发"
- **手段**：声称导师一作能提高接收率，要求学生让位
- **识别线索**：这个说法没有任何实际证据
- **潜台词**："我要占你的学术成果"
- **应对**：要求看期刊的具体署名规则

### M16 "你还不成熟，我帮你把关"
- **手段**：声称学生写的东西不够好需要导师"挂名审核"
- **识别线索**：实际没有提供任何修改
- **潜台词**："占名但不做事"
- **应对**：要求具体贡献清单

## 五、隐私控制类（Privacy Control）

### M17 朋友圈管控
- **手段**：警告学生不要设朋友圈分组、要求加导师好友
- **识别线索**：导师过问学生的朋友圈内容
- **潜台词**："我要监控你的非学术生活"
- **应对**：设置分组（技术性回避），不公开涉及实验室内容

### M18 实习/兼职禁令
- **手段**：禁止学生实习，声称"影响科研"
- **识别线索**：实际和科研无冲突的实习也被禁
- **潜台词**："我不允许你分心于毕业后的事"
- **应对**：了解学校关于实习的正式规定

### M19 监控工具
- **手段**：实验室装摄像头、打卡系统、位置追踪
- **识别线索**：监控超出合理范围
- **潜台词**："你的行踪必须被我掌握"
- **应对**：遵守明面规则，不在监控下说敏感话

### M20 感情生活干涉
- **手段**：干涉学生恋爱、结婚、生育时间
- **识别线索**："博士期间不能XX"之类的要求
- **潜台词**："你的人生节奏我说了算"
- **应对**：原则性问题（生育权等）不让步，策略性问题可以表面配合

---

## 六、情绪投射类（Emotional Projection）

### M21 把自己的焦虑转嫁给学生
- **手段**：导师基金被拒/论文被拒后把气撒在学生身上
- **识别线索**：批评内容和你无关，和他的近期挫折有关
- **潜台词**："我的痛苦你要一起承担"
- **应对**：把这类批评当"天气现象"，不内化

### M22 "我当年比你惨多了"
- **手段**：用自己过去的苦难合理化现在对学生的压榨
- **识别线索**："我读博的时候..."开头
- **潜台词**："你应该感谢我对你已经够好了"
- **应对**：点头听完，不反驳但也不被影响

### M23 "你让我失望了"
- **手段**：使用失望情绪而非具体批评
- **识别线索**："失望"这个词但说不清哪里做错了
- **潜台词**："你要为我的情绪负责"
- **应对**：请求具体反馈："老师能具体说说哪里可以改进吗？"

## 操控识别决策树

```
发现导师某个行为让你不舒服 →
  ├─ 行为有具体可执行的建议？
  │   ├─ YES → 可能是正常批评，执行看看
  │   └─ NO → 向下查
  ├─ 同样的行为是否只针对你一个人？
  │   ├─ YES → 杀鸡儆猴嫌疑（M01）
  │   └─ NO → 向下查
  ├─ 行为是否和导师近期的挫折相关？
  │   ├─ YES → 情绪投射（M21）
  │   └─ NO → 向下查
  ├─ 行为是否涉及越过学术边界？
  │   ├─ YES → 隐私/情感控制（M17-M20）
  │   └─ NO → 记录下来继续观察
  └─ 行为是否会影响毕业/署名？
      ├─ YES → 立刻启动证据保留机制
      └─ NO → 降低内耗，不要过度解读
```

## 防御资源清单

### 证据保留
- 关键沟通走邮件而非微信
- 重要指示当场复述+发邮件确认
- 实验过程保留git commit log、实验笔记
- 长期存在的问题建立私人记录文档

### 社会支持
- 和师兄师姐私下交流（但警惕派系）
- 和导师的其他学生建立组内信任
- 学校心理咨询室（有正式记录）
- 外部朋友/家人作为情感出口

### 制度性资源
- 学校的研究生处/学工部
- 学院学术委员会
- 导师评价网（mysupervisor.org）
- 换导师的正式流程

---

## 核心原则

1. **把操控"命名"出来**——叫出它的名字就削弱了它50%的力量
2. **不内化**——导师的攻击是他的问题，不是你的价值判断
3. **留证据但不主动挑衅**——沉默记录比激烈反抗有效
4. **毕业是唯一目标**——任何策略都围绕"顺利毕业"这个锚点
5. **识别红旗及时止损**——有些导师真的不值得继续，换是最优解
