## 二、组会生存话术模式库

### 2.1 没有进展时的汇报策略

**三段式模板（万能结构）：**
1. **此前做了什么**：描述过去一段时间的工作，哪怕是失败的实验
2. **当前困难是什么**：需要导师帮助的地方，把焦虑转移给导师
3. **下一步规划是什么**：展示你有思路、有计划

**核心策略："汇报问题，而不是汇报进展"**
> "汇报不一定要汇报'进展'，更重要的是汇报'问题'。给导师制造麻烦，反向提问上周遇到的问题，从自己焦虑转化成导师焦虑。"

**水组会分级方案（来自毕导的经典总结）：**

#### 低级水法：
- **随便讲一篇文献**：综述类简单好听但容易被问倒；研究型细节多、台下听不懂、提问少
- **挪用以前的东西**：课程大作业、博资考PPT、开题/中期答辩预演

#### 中级水法：
- **回顾以往论文**：导师可能也借此机会首次弄清你那篇文章干了啥
- **把仅有成果拆着讲**：发动机讲一次、底盘讲一次、车身再讲一次——"省着点用"
  > "万一你一次性把成果都讲了，被导师发现'嚯原来你小子一周就能搞这么多成果！'，下一步就该派你独挑五个横向八个纵向了"

#### 高级水法：
- **讲横向项目进度**：导师极为重视，比听你的科研更上心
- **讲实用知识**：数据可视化、编程语言、搭建博客——"技术含量高，导师能说你什么呢？"
- **讲找工作面经**：大家迫切需要，导师不能把你赶下台
- **讲志愿者经历**：为国家大事做贡献，导师能不支持吗？

### 2.2 被导师批评时的应对话术

**即时反应规则：**
- 先不要急于认错，等导师发泄完再认错
- 太着急认错只会让他觉得你不诚心
- 事后发邮件（不是微信）正式认错——邮件正式，微信太随意

**心理建设：**
- 想象脱敏法：提前想象导师骂你的样子，让自己习惯他的语气用词
- "挨骂也是研究生的一项技能"

**防PUA标准话术模板：**
- 展示备选方案："我最近也在同步推进另一个课题，万一这个方向卡住，咱们还有Plan B兜底"
- 数据驱动反驳："老师，上周我肝了78个样品，但成功率只有12%，您看是不是设备参数需要优化？"
- 彩虹屁化解："真的太佩服您了！要是我有老师一半的毅力，估计现在都发完三篇SCI了"
- 团队话术：用"我们"替代"我"，把导师拉进战壕

### 2.3 向导师表达没进展的委婉话术

**标准回答模板：**
> "目前已完成论文的XX部分（约XX字），正在进行XX部分的写作/实验。预计还需要XX天完成当前阶段工作，计划在XX日前提交给您审阅。"

**遇到困难时的表达：**
> "在XX环节遇到了一些技术问题（具体描述），已经尝试了XX解决方案但效果不理想。想请教您是否有相关经验或建议？"

**3W汇报法：**
- **What**：成果或问题
- **Why**：影响因素
- **Way**：解决方案

## 三、导师-学生权力动态模式

### 3.1 "老板制"本质

中国研究生导师被称"老板"的两大原因：
1. **有钱**：科研项目经费动辄几十万到数百万，全由导师掌控
2. **有权**：决定学生命运——论文答辩、推荐信、就业推荐

> "在博士生看来，导师就是'老板'，和'老板'搞好关系是研究生中流行的一种潜规则"

### 3.2 导师压力来源（理解对手）

1. **职称评定**：讲师→副教授→教授→院士，每一步都需要大量论文
2. **经济压力**：基本工资难以维持体面生活，需要项目经费补贴
3. **考核压力**：每年有考核任务，论文发表是核心指标
4. **时间精力有限**：教学、行政、科研多线并行，只能依靠学生完成科研

### 3.3 大老板 vs 小老板的夹缝生存

**角色关系：**
- 大老板 = 课题组负责人，PI，掌握经费和最终话语权
- 小老板 = 副教授/讲师，通常是大老板的前学生，负责日常指导

**处理分歧的四种方法：**
1. **按级别高低**：谁级别高听谁的（但"县官不如现管"）
2. **按时间先后**：谁先说了听谁的（避免选边站）
3. **按实效大小**：哪个更切合实际就听哪个
4. **兼顾左右**：折中方案，两头都照顾

**更高明的处置：**
- **事前影响法**：想在导师前面，预测分歧点，提前准备方案
- **适当缓办法**：暂时搁置，等时机成熟再处理

**核心原则——"内外有别"：**
1. 没必要让大老板知道的事情就不说
2. 不管什么情况下一定要抬着小老板
3. 不在小老板的学生面前说他的不是

### 3.4 "五大生存法则"（硕士生存攻略）

**法则一：学会示弱，给自己留退路**
- "高开低走让人嫌弃，低开高走让人欣赏"
- 永远在导师面前表现出："我能力有限""我不行""但我会努力"
- 导师会逐步试探能力极限——任务越来越重，退路越来越少
- 控制节奏：慢慢来，显得负责认真

**法则二：学会交好，获得资源支持**
- 力所能及的事能帮就帮
- 公开场合不要直接反驳导师
- "老师这个想法真的不错""老师很厉害"——好话不能少
- 逢年过节私人定制祝福，适量送土特产

**法则三：有效沟通，避免误解**
- 主动透露真实想法（想混学位证就直说、想考公就直说）
- 千万不要让导师对你有过高期待
- 统计发现：绝大多数师生矛盾来自信息不匹配

**法则四：莫较真，识时务者为俊杰**
- "面对导师，正确与否不重要，听话很重要"
- 即使导师说的很荒唐：第一反应不能马上反驳→按他想法来→私下尝试→做不出再慢慢解释
- "他喜欢扯淡，你就陪着扯淡，大家一起开心"

**法则五：必要时的斗争（慎用）**
- 适用于：示弱被骂傻子、不把你当人只当工具、要求做家务接送小孩
- 逐级申诉：辅导员→学院→学校→教育厅→报警
- 前提：你已达到毕业要求 + 前四个法则都试过了

## 四、学术冲突场景模式库

### 4.1 论文署名争议

**常见冲突：**
- 导师抢一作：中国高校中较为普遍，2023年全国高校受理的学术纠纷申诉中，作者排序争议占34%
- 师兄抢一作：利用信息不对称或导师偏袒
- "不挂导师发不出"：部分期刊编辑明确要求导师必须署一作

**应对策略：**
1. 论文撰写初期就与导师讨论署名
2. 保留实验记录、数据分析文件、论文草稿等证据
3. 电子邮件、聊天记录作为辅助材料
4. 寻求学术委员会/学术伦理委员会调解
5. 情节严重时可依据《著作权法》第四十七条主张侵权

### 4.2 被迫换课题

**导师话术：** "上次那个主题我又重新思考了下，我们可以试试全新的方向"

**学生内心：** "我都干了好几个月了你让我换课题？"

**应对策略：**
1. 通过师兄师姐了解课题组哪些方向有基础、有资源
2. 选课题组投入资源多的方向，新开拓方向风险太大
3. 有了意向方向后抓紧与导师讨论，可做成PPT
4. 若被迫选新方向，考虑新老方向结合

### 4.3 组会当众被否定

**场景：** 导师在全组面前指出你的工作"没有意义"/"方向完全错了"

**即时应对：**
- 不要当场激烈反驳（面子管理）
- 可以说："谢谢老师指出来，我回去再仔细想想这个问题"
- 会后私下沟通，准备数据/证据说明

**心理建设：**
- 组会所有同门汇报，进度好坏一目了然
- 心理落差大时容易产生失落感
- 害怕被同门嘲笑是普遍心理

### 4.4 同门竞争/内卷

**表现形式：**
- 组内学生之间暗中比较进度
- 抢占导师资源和注意力
- 争抢项目和署名机会

**潜规则：**
- 不要在同门面前暴露太多真实进度
- 组会上的"信息展示"也是一种竞争
- "隔壁组"是组会中经常被提及的假想敌

## 五、面子管理模式库

### 5.1 中国学术面子文化特征

**儒家文化根基：**
- 重视"和合""尚同"
- "贬己尊人"是中式礼貌最突出特点
- 谦虚被认为是君子之行及有德的表现

**间接表达传统：**
- 中国修辞传统鼓励间接风格（或完全沉默）
- 受中国军事战略直接影响——避免正面对抗
- "话里有话""弦外之音""言外之意"是常态

**学术界人情与面子运作：**
- 匿名评审制度下仍有大量人情空间
- "形式上审稿程序是规范的，但人情和面子的运作并不妨碍关系稿件顺利通过"

### 5.2 给面子 / 留面子 话术

| 场景 | 话术模式 | 面子功能 |
|------|---------|---------|
| 导师说了明显不对的话 | "老师这个角度很新颖，我再想想怎么落地" | 给导师面子，不当面否定 |
| 师兄的方案有漏洞 | "师兄的整体思路很好，我有个小补充" | 留面子式批评 |
| 师妹问了低级问题 | "这个问题其实很多人都会搞混" | 减轻提问者尴尬 |
| 自己的实验完全失败 | "这个结果也有一定的参考价值" | 自我面子维护 |
| 不同意导师的方向 | "我完全理解老师的考虑，同时我也在想..." | 先肯定再提异议 |
| 向导师汇报坏消息 | "总体进展还可以，但有一个地方需要请教" | 铺垫式坏消息传递 |

### 5.3 威胁面子的场景

| 威胁类型 | 具体场景 | 面子损伤等级 |
|---------|---------|------------|
| 当众批评 | 导师在组会上说"你这做的什么东西" | 极高——全组见证 |
| 比较排名 | "你看看师兄做得多好" | 高——社会比较 |
| 能力质疑 | "这么简单的东西你都做不出来？" | 高——智力面子 |
| 公开否定 | "你这个方向完全走偏了" | 高——方向性否定 |
| 私下质疑 | "你最近状态不太好啊" | 中——一对一 |
| 间接暗示 | "XX同学的进度非常好"（暗示你不行） | 中——对比式暗示 |

### 5.4 面子修复策略

1. **自嘲化解**："哈哈是我考虑不周，回去再好好想想"
2. **转移话题**："说到这个，我正好想请教另一个问题..."
3. **承认+转化**："确实是这样，不过这也让我发现了另一个思路"
4. **延迟处理**："这个问题很好，我需要回去仔细想一下再回复您"
5. **拉同盟**："我和师兄也讨论过这个问题，都觉得比较棘手"

## 六、角色话语特征（用于模拟器人设）

### 6.1 导师话语模式

**大老板（院士/大教授）：**
- 宏观叙事："这个领域的未来在于..."
- 画大饼："Nature手到擒来"
- 指点江山式点评
- 很少具体指导，更多是方向性判断
- 口头禅："格局要大""要有高度""这个事情的意义是..."

**小老板（副教授/讲师）：**
- 具体任务导向："这个实验你周五前做完"
- 技术细节把控
- 夹在大老板和学生之间的压力传递者
- 口头禅："大老板说了要...""这个得抓紧""你先把这个弄一下"

### 6.2 学生话语模式

**博士师兄/师姐：**
- 老油条式表达："这个我当年也遇到过"
- 给后辈建议时半真半假
- 口头禅："给你挂个二作"（师兄）/"我家XX"（已育师姐）
- 组会上游刃有余，掌握"拆着讲"的艺术

**硕士研究生（汇报者）：**
- 紧张、准备不足
- 倾向于念PPT而不是讲
- 害怕被问到不会的问题
- 口头禅："这个我还没来得及看""我回去再确认一下"

**低年级新生：**
- 天真直接的提问
- 不懂潜规则容易踩雷
- "师兄/师姐这个是什么意思？"
- 容易被当成免费劳动力

### 6.3 研究生日常词典（于淼版精选）

| 术语 | 讽刺性释义 |
|-----|-----------|
| 研究生 | 本科生用来缓解找不到工作尴尬的高虚荣底薪工作，导师的廉价劳动力 |
| 博后 | 博士生用来缓解找不到工作尴尬的高虚荣底薪工作，导师的廉价高产劳动力 |
| 师兄 | 猥琐全能型NPC，口头禅多为"给你挂个二作" |
| 师姐 | 已婚的为大姐大型NPC，已育后口头禅多为"我家XX" |
| 师弟 | 师姐最常使唤的劳动力 |

## 七、典型冲突剧本模式

### 剧本1："本周没进展"

```
导师：小X，你这周做了什么，给大家汇报一下。
学生：（内心：完了完了完了）呃...老师，这周我主要在...
     （选项A-诚实版）这周实验不太顺利，试剂到了但是...
     （选项B-水法版）这周我读了几篇相关文献，发现一个有意思的点...
     （选项C-反客为主版）老师，关于上次您提到的XX问题，我有几个疑问想请教...
导师：所以你这周的具体产出是什么？
学生：（万能回答）目前在XX环节遇到了瓶颈，我尝试了A方法和B方法，
      但效果不理想。我初步分析可能是XX原因，想请教老师有什么建议？
```

### 剧本2："导师要换课题"

```
导师：我最近在想，你那个方向可能不太好做，要不我们换个思路？
学生：（内心：我TM做了半年了！）
     （选项A-顺从版）好的老师，您觉得哪个方向比较有前景？
     （选项B-谈判版）老师，现在这个方向其实已经有了一些积累，
      如果完全放弃有点可惜。能不能在现有基础上做一些延伸？
     （选项C-拖延版）好的老师我理解您的考虑，我回去先调研一下
      新方向的可行性，下次组会给您一个详细的对比分析。
```

### 剧本3："师兄抢一作"

```
师兄：这篇文章我来写初稿吧，到时候署名的事回头再说。
学生：（内心：回头说就是你一作的意思）
     （选项A-直接版）师兄，这个课题主要是我在做，
      实验数据和分析都是我完成的，一作的事我们先跟导师确认一下？
     （选项B-借刀版）好的师兄，我想我们可以一起跟老师讨论一下
      这篇文章的分工和署名安排。
     （选项C-记录版）好的，那我把我这段时间的实验记录和数据
      整理一份详细文档，方便写作时参考。（暗中保留证据）
```

### 剧本4："大老板和小老板意见不一"

```
大老板：这个课题要从理论角度深入。
小老板（私下）：大老板说的太理想化了，咱们先把实验做出来再说。
学生：（内心：我到底听谁的？）
     （策略）嘴上对两位老师都说"好的"，
      实际按小老板的安排做（因为是日常指导者），
      但在组会上汇报时加入大老板喜欢的理论框架包装。
      核心：明面上两边都不得罪，暗中选最务实的路径。
```

### 剧本5："组会被当众质疑"

```
导师：你这个实验设计有什么依据？我觉得完全不对。
（全组12双眼睛看向你）
学生：（错误反应：脸红、支支吾吾、或者激烈反驳）
     （正确反应）谢谢老师指出来。这个设计参考了XX文献的方法，
      不过确实可能有考虑不周的地方，我回去重新审视一下，
      下次给您一个更完善的方案。
     （会后私下找导师）老师，关于今天组会上的那个问题，
      我查了一些资料，想跟您详细讨论一下...
```

## 八、组会节奏与社交地图

### 8.1 组会典型时间线

1. **开场**（5分钟）：导师训话/布置通知
   - "你们不好好搞通通都是要延毕的"
   - "不要把外面的歪风邪气带到实验室来"
   - "一届不如一届踏实"

2. **汇报阶段**（每人10-20分钟）：
   - 低年级先讲（被试探）
   - 高年级后讲（示范/保底）
   - 导师点评穿插其中

3. **自由讨论**（30分钟）：
   - 导师侃侃而谈，指点江山
   - "Nature手到擒来"式画大饼
   - 学生面面相觑尔后微微一笑

4. **结束**（5分钟）：
   - 导师总结+下周任务
   - "下周谁讲？"——全场沉默的恐怖时刻

### 8.2 组会生态位

| 角色 | 组会行为 | 社交策略 |
|-----|---------|---------|
| 导师 | 坐镇中央，掌握话语权 | 施压+画饼+偶尔表扬 |
| 博士高年级 | 游刃有余，适度展示 | 成果拆着讲，留后手 |
| 博士低年级 | 谨慎汇报，避免出头 | 跟着师兄师姐的节奏 |
| 硕士 | 紧张准备，怕被问 | 讲文献水过去 |
| 本科实习生 | 旁听为主 | 保持低调不出声 |
